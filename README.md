# Face Puzzle Game

Aplikasi clone dari game sliding face puzzle. Dibangun menggunakan React, Vite, dan Tailwind CSS.

## Cara Menjalankan di Komputer Lokal

1. Pastikan [Node.js](https://nodejs.org/) sudah terinstal di komputer.
2. Ekstrak file ZIP ini ke dalam sebuah folder.
3. Buka terminal atau command prompt, lalu arahkan ke folder yang diekstrak.
4. Jalankan perintah instalasi dependency:
   ```bash
   npm install
   ```
5. Jalankan development server:
   ```bash
   npm run dev
   ```
6. Buka browser dan akses link localhost yang tertera di terminal (biasanya `http://localhost:5173`).
